# Badge Studio — Product Badges & Labels

## Subtitle
Create clear, customizable labels for selected products in minutes.

## Short description
Add “New”, “Sale”, “Bestseller”, and custom badges to product pages without editing theme code.

## Full description
Badge Studio helps merchants highlight products with simple, on-brand labels. Select products in Shopify Admin, choose the badge position and colors, preview the result, and publish through Shopify's theme editor.

Key features:

- Create text badges for one or many products.
- Choose top-left, top-right, bottom-left, or bottom-right placement.
- Customize background color, text color, font size, and corner roundness.
- Preview badge appearance before publishing.
- Add or remove the Theme App Extension block without changing theme files.
- Clean removal: merchant configuration is deleted after uninstall/redaction.

## Search terms
product badge, product label, sale badge, bestseller, new arrival

## Setup instructions
1. Install Badge Studio and open it from Shopify Admin.
2. Create a badge and select the products where it should appear.
3. Go to Online Store > Themes > Customize and open the default product template.
4. Add the “Product badge” app block near the product media and save.

## Reviewer test instructions
Install the app on a development store with at least one product. Create a badge, select that product, then add the Product badge app block to the product template. Visit the selected product to verify the badge. Delete the badge to verify it disappears.
